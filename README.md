# Project2bNew
This is a guide on how to use the interface for our program
Below is the interface/Main Menu.

Using the program
Main Menu
1. Generate Dataset
2. Select Dataset Size
3. Select Input Distribution
4. Run Merge Sort
5. Run Quick Sort
6. Compare Results
7. Exit

1. The first thing you want to do is set the settings for the dataset you want to generate which should be done in option 2 and 3
IMPORTANT!!! : After selecting one of the options and selecting the settings, ensure you hit "enter" once the program loads to take you BACK to the main menu, if you try to select another menu choice before
doing this then nothing will happen
2. After selecting your settings, generate the dataset using option 1
3. Then run both merge sort and quick sort (remember to hit enter after each algorithm is done) the program will display the statistics of the algorithm when done
4. Then choose option 6 to compare the results of both algorithms for the dataset you generated

Thank you!!!
